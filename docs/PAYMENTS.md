# طرق الدفع — الإعداد الكامل

ثلاث طرق مستقلة. تقدر تفعّل أي وحدة أو كلهن من ⚙️ لوحة التحكم → 💳 الدفع.

| الطريقة | التأكيد | تحتاج | الرسوم |
|---------|---------|-------|--------|
| 🅱️ **Binance Pay** | يدوي (موافقتك) | معرّف Binance Pay فقط | صفر |
| 🪙 **Cryptomus** | آلي (ويبهوك) | حساب تاجر + مفتاحين | ~0.4% |
| ⭐️ **Telegram Stars** | آلي (فوري) | لا شي | ~30% عمولة تلغرام |

---

## 1) Binance Pay — الأسهل، ابدأ فيه

### ليش يدوي؟
التحقق الآلي بدّه حساب **Binance Merchant** بعقد ومراجعة KYC للشركة. المتاح لأي حد هو التحويل الداخلي المجاني عبر Binance Pay ID — وهاد بالضبط يلي بيستعمله GGSoma.

### الإعداد
1. افتح تطبيق Binance → **Pay** → فوق بتلاقي **Pay ID** (رقم من 9-10 خانات)
2. بالبوت: ⚙️ → 📝 النصوص → **معرّف Binance Pay** → الصق الرقم
3. ⚙️ → 💳 الدفع → تأكد إنو **Binance Pay مفعّل** 🟢

### كيف بيشتغل
```
الزبون يدخل المبلغ
   ↓
البوت يعرض Pay ID + المبلغ + مهلة 30 دقيقة
   ↓
الزبون يحوّل ويلصق رقم العملية (TxID)
   ↓
بتوصلك بطاقة فيها [✅ موافقة] [❌ رفض]
   ↓
موافقتك تشحن الرصيد فوراً
```

**حماية مبنية بالكود:** نفس رقم العملية ما بينفع يُستعمل مرتين، والموافقة المكررة ما بتشحن مرتين.

⚠️ **تحقّق من وصول التحويل بحسابك فعلياً قبل الموافقة.** الزر ما بيتحقق — إنت بتتحقق.

## 2) Cryptomus — آلي بالكامل، أي شبكة

### الإعداد
1. سجّل على [cryptomus.com](https://cryptomus.com) → **Business** → أنشئ متجر
2. من إعدادات المتجر خد:
   - **Merchant UUID** → `CRYPTOMUS_MERCHANT_ID`
   - **Payment API key** → `CRYPTOMUS_API_KEY`
3. بإعدادات الويبهوك حط الرابط:
   ```
   https://<خدمتك>.onrender.com/hooks/cryptomus/<WEBHOOK_SECRET>
   ```
   نفس قيمة `WEBHOOK_SECRET` تبعتك بالضبط.
4. (اختياري) اسمح لـ IP تبع كريبتوموس: `91.227.144.54`

### كيف بيشتغل
الزبون يدخل المبلغ → البوت ينشئ فاتورة → يفتح صفحة كريبتوموس → يدفع بأي عملة وأي شبكة → الويبهوك يجي → **الرصيد بينضاف تلقائياً**.

### الأمان
كل ويبهوك بينتحقق بتوقيع `md5(base64(json) + API_KEY)` بمقارنة ثابتة الزمن. أي توقيع غلط بينرفض وبيوصلك تنبيه — لأنه لو ما تحققنا، أي حد بيعرف الرابط بيقدر يشحن حاله مجاناً.

وكمان: لو المبلغ المدفوع أقل من المطلوب بأكتر من 2%، الدفعة بتنرفض وبتوصلك.

## 3) Telegram Stars — فوري، بدون أي حساب خارجي

### الإعداد
ولا شي. بيشتغل من أول لحظة. بس تأكد ⚙️ → 💳 الدفع → **Telegram Stars مفعّل** 🟢

### الإعدادات القابلة للتعديل
| الإعداد | الافتراضي | المعنى |
|---------|-----------|--------|
| قيمة النجمة بالدولار | `0.009` | 50⭐️ = 0.45$ |
| باقات النجوم | `50,100,250,500,1000` | الأزرار الجاهزة |
| أقل / أقصى عدد نجوم | `50` / `100000` | حدود الإدخال اليدوي |

### تنبيه مهم على الأرباح
**تلغرام بياخد حوالي 30% عمولة على النجوم** (حصة متجر التطبيقات). يعني 100⭐️ بيدفعها الزبون بحوالي 1.30$، وبتوصلك ~0.90$.

قيمة `0.009` الافتراضية معمولة على هالأساس. **لا تحطها أعلى** إلا إذا حسبت العمولة — وإلا كل شحنة نجوم بتخسرك.

### سحب النجوم
من BotFather → بوتك → **Bot Settings → Balance**. النجوم بتنسحب كـ TON بعد 21 يوم من الاستلام.

## متغيرات البيئة على Render

### إلزامية دائماً
| المتغير | من وين |
|---------|--------|
| `BOT_TOKEN` | BotFather |
| `ADMIN_IDS` | [@userinfobot](https://t.me/userinfobot) — أرقام مفصولة بفواصل |
| `WEBHOOK_URL` | رابط خدمة Render، **بدون / بالآخر** |
| `WEBHOOK_SECRET` | نص عشوائي طويل — Render بيولّده |
| `GG_API_KEY` | بوت GGSoma → API 🔑 |
| `GG_BASE_URL` | `https://ggsoma.store/api/partner/v1` |
| `SUPABASE_URL` | Supabase → Settings → API |
| `SUPABASE_SERVICE_KEY` | نفس المكان — مفتاح `service_role` |
| `PORT` | `3000` |

### لـ Cryptomus فقط
| المتغير | من وين |
|---------|--------|
| `CRYPTOMUS_MERCHANT_ID` | Cryptomus → Business → إعدادات المتجر |
| `CRYPTOMUS_API_KEY` | نفس المكان — **Payment API key** |
| `CRYPTOMUS_PAYMENT_KEY` | اختياري. لو مفتاح الويبهوك مختلف، حطه هون |

**Binance Pay و Telegram Stars ما بدهم ولا متغير بيئة.** كل إعداداتهم من جوّا البوت.

## قائمة فحص قبل استقبال فلوس حقيقية

- [ ] `WEBHOOK_URL` بدون `/` بالآخر
- [ ] رابط ويبهوك كريبتوموس مطابق لـ `WEBHOOK_SECRET` حرف بحرف
- [ ] جرّب دفعة Stars بـ 50 نجمة على حسابك — لازم الرصيد يزيد فوراً
- [ ] جرّب Cryptomus بـ 1$ — لازم الرصيد يزيد بدون تدخّل منك
- [ ] جرّب Binance Pay — لازم توصلك بطاقة الموافقة
- [ ] اضغط زر الموافقة **مرتين** — لازم يشحن مرة وحدة بس ويقول «انشحنت من قبل»
- [ ] راقب logs الخدمة لأول دفعة — دوّر على `[cryptomus] توقيع غير صالح`

> آخر بند هو الأهم. لو التوقيع بيفشل، معناها المفتاح غلط، ولا دفعة كريبتوموس رح تنشحن.
