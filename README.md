# بوت متجر اشتراكات — فوق GGSoma Partner API

بوت تلغرام لبيع الاشتراكات الرقمية بتسليم فوري، مع لوحة تحكم كاملة داخل البوت.

```
زبونك ──> بوتك ──> GGSoma Partner API ──> رابط / كود / حساب
        (رصيده عندك)  (رصيدك عندهم)
```

عندك محفظة **وحدة** عند GGSoma بتشحنها إنت. زبائنك عندهم محافظ بقاعدة بياناتك.
ربحك = سعرك للزبون − تكلفتك عند GGSoma.

📄 **[دليل التشغيل الكامل](docs/RUNBOOK.md)** · [طرق الدفع](docs/PAYMENTS.md) · [متطلبات API](docs/API.md)

**للزبون**

## طرق الدفع

| الطريقة | التأكيد | الإعداد |
|---------|---------|---------|
| 🅱️ **Binance Pay** | يدوي بموافقتك | معرّف Pay ID فقط |
| 🪙 **Cryptomus** | آلي عبر ويبهوك موقّع | حساب تاجر + مفتاحين |
| ⭐️ **Telegram Stars** | آلي فوري | ولا شي |

كل الشحنات بتمرق من دالة `credit_payment` الذرّية — الويبهوك ممكن يجي مرتين والأدمن ممكن يضغط موافقة مرتين، والرصيد بينشحن **مرة وحدة بس**.

التفاصيل بـ [docs/PAYMENTS.md](docs/PAYMENTS.md).

## التسعير — هامش ثابت، سعر متحرّك

```
سعرك = تكلفتك × (1 + 40%)
```

التكلفة بتنقرأ من GGSoma **كل مزامنة**، فالسعر بيتحرّك معها تلقائياً:

| تكلفتهم | سعرك | لو نزلت لـ 1.00$ |
|---------|------|------------------|
| 2.00$ | 3.00$ | → **1.50$** تلقائياً |
| 5.00$ | 7.50$ | → **1.50$** تلقائياً |

**ضمان الهامش بعد الخصم** (مفعّل افتراضياً): السعر بينحسب بحيث الهامش يضل 40% **حتى للزبون صاحب أعلى مستوى**. بدونه، خصم المستوى بياكل من ربحك.

الشي الوحيد يلي بيكسر التتبّع هو **السعر اليدوي**. لما تحطه، المنتج بيوقف عن متابعة التكلفة — ولوحة التحكم بتوريك كم منتج بهالحالة مع زر لإلغائهم كلهم.

وبيوصلك إشعار لما تتحرّك تكلفتهم بأكتر من 10% — **بالاتجاهين**. النزول مهم متل الطلوع: ساعتها سعرك بينزل لحاله، وممكن تفضّل تثبّته وتاخد ربح أكبر.

## حارس الهامش

GGSoma بترفع `yourPrice` وقت ما بدها. لو عندك سعر يدوي أو زبون بمستوى عالي عنده خصم، ممكن تبيع بخسارة وما تنتبه إلا بعد عشر عمليات.

كل مزامنة، الحارس بيحسب **أوطى سعر ممكن يدفعه أي زبون** (بعد أعلى خصم مستوى) وبيقارنه بالتكلفة الجديدة:

- الهامش تحت الحد → **البيع بيوقف تلقائياً** + إشعار فيه زر «عدّل السعر»
- عدّلت السعر → **بيرجع البيع لحاله** بالمزامنة الجاية

وفي دفاع ثاني وقت الشراء نفسه — حتى لو الحارس ما لحق يوقفه، الطلب بينرفض.

الحدّ من ⚙️ التسعير → «أقل هامش مسموح %» (افتراضي 5%).

## التنسيق الكامل مع GGSoma

إنت بتتحكم بـ **السعر وشكل البوت** بس. كل الباقي بينسحب تلقائياً كل مزامنة:

| الشي | من وين | التصرّف |
|------|--------|---------|
| الأسماء والأوصاف والتعليمات | `GET /catalog/products/:ref` | بتنسحب وبتتنظّف لتلغرام |
| المخزون والحالة | `GET /catalog/products` | بينعكس فوراً على الأزرار (🟢/🔴) والعدد |
| المدة والضمان ونوع التسليم | نفسه | بيظهر بصفحة المنتج |
| المزوّدين والإيموجي والترتيب | `GET /catalog/providers` | القوائم بتنبني منه |
| **منتج جديد** | مقارنة مع الدورة السابقة | بينضاف + إشعار للمشتركين |
| **زيادة مخزون** | فرق `stock_count` | إشعار «تمت إضافة مخزون جديد!» |
| **منتج انحذف عندهم** | غاب عن الكتالوج | `deleted_at` + بينخفى + تنبيه للأدمن |

### إشعار المخزون

بنفس ترتيب بوت GGSoma بالضبط:

```
┃ ✨ تمت إضافة مخزون جديد!

تمت الإضافة: 250
المخزون الحالي: 524

⚡ اسرع الآن لشراء الخدمة!

┃ ✨ Gemini Pro 18 Months رابط
[ ✨ شراء الآن ]
```

الزر بينقل الزبون لصفحة المنتج عندك مباشرة.

النقصان بالمخزون **ما بينبّه عليه** — لأنه طبيعي (مبيعات). بس الزيادة.

### سحب التفاصيل تحت الحد

مسار القائمة ما بيرجّع الأوصاف والتعليمات — لازم نداء منفصل لكل منتج، وحدّهم 60/دقيقة. فالمزامنة بتسحب **15 منتج بالدورة** (قابل للتعديل): الجديد أولاً، بعدين الأقدم تحديثاً. خلال دورتين تلاتة بيكون كل الكتالوج مسحوب، وبعدين بيتجدّد بالتناوب.

### تنظيف HTML

نصوصهم بترجع أحياناً بـ `descriptionFormat: "HTML"` وفيها `<div>` و`<ul>` — تلغرام بيرفضها ويفشّل الرسالة كلها. `src/lib/html.js` بيحوّل الوسوم البنيوية لأسطر، بيشيل غير المدعوم، وبيقفل الوسوم المفتوحة وبيشيل اليتيمة.

## القاعدة الذهبية

على timeout أو انقطاع شبكة أثناء الشراء: **لا ترجّع الرصيد**.

ما بتعرف إذا الطلب نجح عند GGSoma أو لأ. لو رجّعت والطلب كان نجح — إنت دفعت والزبون أخد فلوسه. خسارة صافية.

الصح: خلّي الطلب `PENDING`، والمُصالح بيسأل `GET /orders?externalOrderId=…` كل دقيقة ويحسمها. لأن الـ `externalOrderId` idempotent، إعادة المحاولة ما بتخصم مرتين.

الإرجاع بس على الأخطاء النهائية: `OUT_OF_STOCK`، `PRODUCT_NOT_FOUND` وأخواتها.

## ملاحظات تشغيلية

**رصيدك عند GGSoma** — لو فضي، كل زبائنك بيوقفوا فوراً. التنبيه مضبوط على 20$، عدّله من ⚙️ الإشعارات.

**`READY_ACCOUNT`** — بيانات دخول حقيقية، مخزّنة بـ `orders.delivery`. فعّل Row Level Security على الجدول ولا تعرضه من أي client.

**الضمان** — GGSoma بترجّعلك `warranty.days` لكل منتج. لازم يكون عندك سياسة مكتوبة وواضحة، وإلا الاستبدالات بتاكل ربحك.

**الحسابات المشتركة** — بيع اشتراكات ChatGPT / Netflix / Spotify بحسابات مشتركة بيخالف شروط استخدام هالمنصات، والحسابات بتنحرق. نسبة الاسترجاع بهالفئة أعلى بكتير. ابدأ بمنتجات `LINK` و`COUPON`.

**الكود مو الجزء الصعب.** يلي بيحدد إذا بتربح هو المورّد والضمان والاسترجاعات.
